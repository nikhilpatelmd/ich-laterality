# Hemispheric Lateralization and Functional Outcomes in ICH

Pooled Analyis of ATACH-2 and ERICH

## Reproducing this analysis

This project uses `renv` for package management. Raw data not included. To set up the required R environment:

1. Clone this repository
2. Open R in the project directory
3. Install renv: `install.packages("renv")`
4. Restore the project environment: `renv::restore()`
